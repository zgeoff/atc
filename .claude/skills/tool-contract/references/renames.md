# Tool renames

A tool rename is a breaking change with no alias in code. The old name is refused: `unknown tool` on
stdio, or a missing-scope refusal for a remote client without the `kill` scope. A name atc does not
know needs the strictest scope. No tool translates an old daemon's words. A daemon on another
protocol version refuses the handshake with `protocol_mismatch` before any tool call reaches it
([the protocol](../../../../docs/architecture/protocol/protocol.md#versions)).
